What the AI actually wrote

Real replies from Claude Haiku 4.5 with this prompt, one per case, each written fresh from new facts (different meals and numbers from the prompt’s examples). Shown as they came back, with only the light formatting the AI used. Each was checked: every percentage is one it was given, with the right sign; every meal is named; nothing about what a meal “could have added”; no em dash; within the word limit.

Guardrails for the build

  • The app owns the numbers. Changes, scores and grams are sent ready. The AI only talks about them, and may only repeat them.
  • Clean up first. Replies often use ' for ’. Replace it before showing.
  • Check before showing. Every percentage in the reply is one that was sent, with the same sign; every meal is named; no “could have added”; no em dash; under the word limit. If a check fails, show the timeline template’s own sentences instead, built from the same facts.
  • Render light markdown only. Bold and paragraphs. Nothing else is used.
  • Low temperature. Warm but steady: the same facts should read much the same each time.
  • Same macro rule everywhere. 80% to 120% is a placeholder until it matches the score’s own rule.
