Custom icons

No exercise icons exist in the GoodFlip Figma file and no licence-safe filled icon exists on Iconify for these, so they are drawn by hand to match MingCute Fill: 24 grid, 2px padding, round head, 4px torso, 2.2 to 2.5px limbs with round ends, filled only. Poses follow ACE, NHS and exercise-guide references.

  • Crunch variants (Bicycle Crunches, Reverse Crunch): use family-abs
  • Arm circles, shoulder rotation: use family-arm-raise
  • Box Breathing, Diaphragmatic breathing: use family-breathing
  • Wall Squat: use family-squat
  • Clamshell, Flutter Kick: use family-leg-raise
  • Sprawls: use family-burpee

Log activities

Order of preference: reuse an icon already in the log list or this set, then a licence-safe filled icon (Material Symbols Rounded filled, MDI, Temaki CC0), then custom figures drawn to match MingCute Fill from reference images.
